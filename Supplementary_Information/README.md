## Supplementary Information

The [CAMPD Glossary](/Supplementary_Information/CAMPD-Glossary.pdf) provides definitions and example values of the data supplied by CAMPD.

The [Plain English Guide to the Part 75 Rule](/Supplementary_Information/Plain_English_Guide_to_the_Part_75_Rule.pdf) offers a simplified overview of 40 CFR Part 75. While it is **not a substitute for the full regulatory text**, it serves as a helpful resource for general understanding.
