# 2. Exploratory Data Analysis (EDA)

The data is explored through the following analyses:

- **Temporal behavior:** Visualized using line charts and autocorrelation analysis.  
- **Variable distributions:** Examined by e. g. boxplots for pollutants, pie charts for electricity contributions by fuel type or unit type.  
- **Variable relationships:** Assessed using Spearman correlation and Kruskal-Wallis tests.
